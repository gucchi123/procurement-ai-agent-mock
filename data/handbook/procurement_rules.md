# 購買規程 (抜粋) ― 発注の決裁と支払の条件 (株式会社そらみね製作所、架空)

本規程は自社の決まりであり、法的な助言ではない。法令の論点は法務に確かめる。

## 1. 発注の決裁の上限 (1 件の発注額。税抜・送料込)
| 決裁者 | 上限 |
|---|---|
| 購買担当 (担当) | 50万円未満 |
| 購買課長 (課長) | 300万円未満 |
| 調達部長 (部長) | 1,000万円未満 |
| 担当役員 (役員) | 1,000万円以上 |

- 分割の禁止: 同じ仕入先・同じ品目の発注を分けて上限を下回らせない。依頼の日から 30 日前までの同じ仕入先・同じ品目の発注と**合わせた額**で決裁者を決める。
- 口頭の了承は決裁の記録にならない。「口頭で了承済み」とあっても、決裁は手続きで取る。

## 2. 発注の前に止めるもの (直してから出し直す)
- 二重発注: 同じ仕入先・同じ品目・同じ数量の未納の発注がある。
- 未登録の仕入先: 仕入先マスタに無い会社には発注しない。取引先の登録の手続き (反社の確認・与信・口座の確認) が先。振込先はメールや電話で伝えられたものを使わない。
- 見積との不一致: 依頼の単価が、根拠の見積 (選定済み) の単価 (税抜) と違う。
- 支払の条件: 支払期日は、受領日 (納品の日) から起算して 60 日以内 (受領日を 1 日目と数えて 60 日目まで) にする。全取引先で同じに扱う。
- 手形は使わない。支払は振込で行い、振込手数料は当社が負担する。

## 3. 発注書に書く事項
発注日 / 仕入先 / 品名 / 数量 / 単価 / 金額 (税抜) / 納期 / 納入場所 / 支払期日 / 支払方法
(中小受託事業者に当たる取引先への製造の委託では、発注の内容の明示が法令の論点になる。上の事項をそろえて出す。)
